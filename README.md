# 叠栏 · FoldBar

让被刘海挡住的菜单栏图标，收进一个 **···**。

FoldBar 是一个 macOS 菜单栏图标管理工具。启动后自动收起隐藏区，点击顶部 **···**，即可在一条简洁的浮条中查看隐藏项目。常用应用可以放回菜单栏，不常用的留在隐藏栏。

**当前版本：1.5.1 预览版 · 构建 16 · Apple Silicon**

[下载安装包](https://github.com/FreyaH218/FoldBar/releases/tag/v1.5.1-preview.1) · [更新记录](CHANGELOG.md) · [验证记录](VALIDATION.md)

## 主要功能

- **默认收起**：启动时先准备原图，再收起隐藏区；正常启动不弹出浮条。
- **三个点入口**：收起后仍保留顶部 **···**，随时打开隐藏栏。
- **原始图标**：按原始尺寸显示菜单栏图标，包括速率等文字状态；已读取的原图不会被空白帧覆盖。
- **常驻与排序**：将常用项目移到顶部菜单栏，调整顺序，或收回隐藏区。
- **紧凑显示**：图标过多时可横向滚动或翻页，名称在悬停时显示。
- **按需整理**：搜索、权限、开机启动等操作都在右侧齿轮菜单中。

## 安装与首次启动

1. 在 [Releases](https://github.com/FreyaH218/FoldBar/releases/tag/v1.5.1-preview.1) 下载 `FoldBar-macOS-AppleSilicon.zip`。
2. 解压，将 `FoldBar.app` 放到固定位置，例如“应用程序”，然后打开。
3. 按应用提示开启以下两项权限。缺少权限时，浮条会显示相应的授权入口。
4. 授权后退出并重新打开 FoldBar。图标准备完成后会自动收起；点击菜单栏 **···** 开始使用。

| 权限 | 用途 | 系统设置位置 |
| --- | --- | --- |
| 辅助功能 | 识别、移动菜单栏项目并打开原菜单 | 隐私与安全性 → 辅助功能 |
| 录屏与系统录音 | 读取其他应用真实的菜单栏图标 | 隐私与安全性 → 录屏与系统录音（旧系统可能称“屏幕录制”） |

FoldBar 只读取已识别的菜单栏小窗口静态图像，**不录音、不保存图像、不上传数据**。录屏权限名称由 macOS 决定，系统可能显示相应的隐私指示图标。

此版本采用临时签名，尚未进行 Apple Developer ID 签名和公证。若系统阻止打开，可从源码构建；无需关闭系统安全检查。

## 主要用法

### 查看和打开隐藏项目

点击顶部 **···** 打开图标条，再点击一次即可关闭。单击图标可打开对应原菜单；如果应用没有提供菜单打开接口，FoldBar 会尝试把它的原图标移到顶部。悬停可查看名称和操作提示。

图标较多时，横向滚动或点击两侧箭头查看其余项目。

### 让应用常驻菜单栏

打开 **齿轮 → 管理常驻图标**，会出现两排：

- **上排“常驻菜单栏”**：实际显示在顶部菜单栏的项目。
- **下排隐藏项目**：平时收起、点击 **···** 才查看的项目。

将下排图标拖到上排，即可申请常驻；在上排拖到目标图标前面可调整顺序；把上排图标拖回下排可隐藏。完成后点击 **完成**，回到单排浮条。

也可以直接把隐藏图标拖到屏幕顶部 **···** 右侧的蓝色接收区，松手后放回菜单栏。拖到桌面其他位置或取消拖动不会移动原图标。

**拖动不生效时**，右键图标，选择 **常驻菜单栏** 或 **收回隐藏区**。FoldBar 移动的是应用本身的菜单栏项目；顶部图标和菜单仍由原应用提供。完整拖放手势在不同应用上的兼容性仍待验证。

### 临时展开、搜索和设置

| 想做什么 | 操作 |
| --- | --- |
| 打开 / 关闭隐藏图标条 | 点击 **···**，或按 `⌥⌘B` |
| 临时展开 / 收起原菜单栏 | `⌥` 点击 **···**，或按 `⇧⌥⌘B` |
| 搜索全部菜单项目 | 齿轮 → **搜索图标…** |
| 更新图标 | 齿轮 → **刷新图标** |
| 查看原图读取情况 | 齿轮 → **图标读取状态…** |
| 登录 Mac 时启动 | 齿轮 → **登录 Mac 时启动** |
| 恢复边界位置 | 齿轮 → **恢复菜单栏布局** |
| 退出应用 | 齿轮 → **退出叠栏** |

退出 FoldBar 后，原菜单栏项目会恢复空间。菜单栏空间仍受屏幕宽度限制，无法把所有图标同时放进刘海右侧。

## 更新后权限失效怎么办？

临时签名版本更新后，本机验证发现：仅关闭再开启权限开关可能无效。请按下面的方法重新关联当前应用：

1. 系统设置 → 隐私与安全性 → **辅助功能**。
2. 选中 **FoldBar**，用 **－** 移除，再用 **＋** 添加更新后的 `FoldBar.app`。
3. 如果原图仍未显示，在 **录屏与系统录音** 中对 FoldBar 做同样处理。
4. **退出并重新打开 FoldBar**，让权限生效。

只需处理 FoldBar 的条目。升级或移动应用后，请确认添加的是实际使用的那一份。

## 图标只显示文字或移动失败

- 原图未读到时会暂时显示名称缩写。先检查录屏权限，再退出重开，或使用 **刷新图标**。
- 在 **图标读取状态…** 中查看未读取的项目。图像只缓存在内存中，首次启动需要重新读取。
- 移动失败时会保留展开状态并显示原因；可尝试右键菜单中的常驻 / 收回操作。
- 时钟、控制中心及系统隐私指示项等控件，可能由 macOS 固定，无法像普通应用一样隐藏或移动。

## 兼容性与验证范围

当前下载包适用于 **Apple Silicon Mac**，已在 **macOS 26.6.2** 实机验证默认收起、固定入口及原始图标显示；本机一次重启验证读取到 **18 / 18** 个原图。另有 **73 项核心检查**通过。

该结果不代表所有应用和机器均兼容。Intel、macOS 13–15、多显示器、全屏空间及所有第三方拖放手势尚未完整实测。**macOS 27 起停用折叠功能**。详细记录见 [VALIDATION.md](VALIDATION.md)。

## 从源码构建

需要 Apple Command Line Tools 或 Xcode，以及 Swift 5.9 或以上版本，无外部依赖。

```bash
git clone https://github.com/FreyaH218/FoldBar.git
cd FoldBar
bash scripts/build.sh
bash scripts/check-core.sh
```

生成的应用位于 `dist/FoldBar.app`。[技术说明](docs/TECHNICAL.md)包含实现方式、系统接口和当前限制。
